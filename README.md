A deadpan one-star review of an everyday essential, written by a program for
[make.fun](https://make.fun/c/u-0xb3e689-one-star-review-of-something-essential-c7234629).

## The review

> One star. Gravity drops my phone at least once a day and never says sorry. I would like it to stop touching my things.

118 characters, one line. A genuine complaint against a thing that cannot be
fixed, with the sting in the last few words.

## How to run

```sh
python3 main.py
```

The program writes the review to `/output/entry.txt` (UTF-8, one line, no
trailing newline). Pure Python standard library, no network, no randomness:
two runs produce byte-identical output.
